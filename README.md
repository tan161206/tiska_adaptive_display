# TISKA — Adaptive Display

TISKA is an interactive productivity experience designed around three modes: Focus, Flow, and Rest.

## Features
- Focus timer and task management
- Flow mode with customizable wallpapers and sound options
- Rest mode with a relaxing visual experience
- Responsive layouts for desktop, tablet, and mobile
- Interactive controls and animated visual effects

## Technology
- Framer
- React and TypeScript for code components
