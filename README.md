## 📌 About the Project

**TISKA** is an interactive digital experience designed to adapt to different moments of the day. It brings together three distinct environments — **FOCUS, FLOW, and REST** — within one cohesive interface.

The idea behind TISKA is simple: productivity is not the same for everyone, and it does not look the same throughout the day. Sometimes we need concentration, sometimes an energetic environment, and sometimes a calm space to relax.

Built using **Framer**, TISKA explores interactive product design through reusable components, component variants, animations, and user interactions.

## ✨ Features

### 🎯 FOCUS — Concentration & Productivity
- Focus timer with timer controls.
- Task management to organise work.
- Customisable wallpapers.
- Sound selection for a personalised working environment.
- A clean, distraction-conscious interface.

### 🎧 FLOW — Energy & Immersion
- Gaming-inspired visual themes.
- Neon aesthetics and energetic backgrounds.
- Sound options for an immersive experience.
- A distinctive visual identity separate from Focus.

### 💤 REST — Relaxation & Calm
- Warm colours and a relaxing atmosphere.
- A softer visual experience.
- A dedicated interface designed for downtime.

### 🎨 Interactive Design
- Three selectable modes with distinct appearances.
- Animated interactions and hover effects.
- Explore TISKA transition.
- Responsive layout considerations.
- Reusable components and component variants.

## 🚀 Getting Started

### Option 1: Explore the live website

The simplest way to experience TISKA is through the published website.

1. Open the [TISKA Live Demo](https://good-illuminate-349765-1d95e72f4.framer.app/).
2. Click **Explore TISKA**.
3. Choose Focus, Flow, or Rest.
4. Explore the available features and interactions.

### Option 2: Access the GitHub repository

Clone the repository to your local machine:

```bash
git clone https://github.com/tan161206/tiska_adaptive_display.git
cd tiska_adaptive_display
```

**Note:** The interactive website is built and published through Framer. Cloning this repository alone will not reproduce the complete website locally unless the required application source code and dependencies are included.
